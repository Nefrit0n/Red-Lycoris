# Продукт-Лицензирование

Лицензия приложения, лицензии зависимостей и условия внешних наборов данных рассматриваются отдельно. Apache 2.0 проекта не переопределяет условия сторонних компонентов и источников обогащения. Сведения об условиях внешних источников проверены 4 сентября 2026 года; неустановленные условия отмечены явно.

## EPSS

FIRST публикует оценки EPSS бесплатно, без регистрации, и просит указывать источник при использовании данных в продуктах и публикациях. Это относится к опубликованным оценкам, а не к исходной телеметрии и внутреннему процессу обучения модели. Для атрибуции используйте указание EPSS и ссылку на FIRST. [Официальные ответы FIRST](https://www.first.org/epss/faq).

Red Lycoris загружает ежедневные файлы оценок; в коде предусмотрены адреса Cyentia, Empirical Security и резервный источник GitHub. [https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/enrichment/epss/sync.go](https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/enrichment/epss/sync.go).

## CISA KEV

Официальный репозиторий CISA распространяет БД KEV по CC0 1.0. Условия сторонних сайтов, на которые ссылаются записи каталога, остаются отдельными. Использование данных не даёт права на логотип CISA или печать DHS и не означает одобрения продукта этими организациями. [Лицензия KEV](https://github.com/cisagov/kev-data/blob/develop/LICENSE).

Синхронизатор получает JSON-каталог с сайта CISA: [https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/enrichment/kev/sync.go](https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/enrichment/kev/sync.go).

## OSV

OSV агрегирует записи из разных баз. Для данных применимы условия исходных баз, а не единая лицензия программного кода OSV. Официальный список источников, например, указывает CC-BY 4.0 для GitHub Advisory Database, PyPI и Go Vulnerability Database; CC0 1.0 для Rust Advisory Database; CC-BY-SA 4.0 для Ubuntu. [Источники и лицензии OSV](https://google.github.io/osv.dev/data/).

При передаче данных третьим лицам сохраняйте сведения об их происхождении и проверяйте условия соответствующей исходной базы, включая атрибуцию и условия распространения производных материалов. Загрузка архива одной экосистемы не означает, что все записи имеют одинаковую лицензию. Это следует из агрегации разных источников, описанной OSV.

Red Lycoris загружает архивы по экосистемам: [https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/enrichment/osv/sync.go](https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/enrichment/osv/sync.go).
