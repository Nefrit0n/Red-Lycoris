# Пользователь-Работа-с-находками

Страница «Находки» объединяет доступные пользователю проекты. Просмотр, поиск, фильтрация, настройка таблицы и открытие карточек доступны роли «Просмотр» и выше. Изменения данных требуют роли «Триаж» и выше; порядок действий приведён в [Триаже](Пользователь-Триаж).

## Поиск и фильтрация

Роль: просмотр и выше.

1. Откройте «Находки». Для поиска нажмите поле «Поиск… (/)» слева либо клавишу `/` вне редактируемого поля.
2. Введите слова из названия, описания или компонента. Это полнотекстовый поиск, а не поиск произвольной подстроки во всех полях карточки.
3. Выберите вкладку типа: все находки, SCA, SAST, DAST, IaC, секреты либо прочие. Переключение типа не сбрасывает остальные фильтры.
4. Уточните выборку фильтрами из таблицы ниже. Для изоляции одного проекта выберите его в разделе «Проекты».
5. При необходимости сбросьте фильтры кнопкой сброса в панели.

Проверка результата: адрес страницы содержит параметры выбранной выборки, а таблица — соответствующие находки. Откройте контрольную запись и проверьте проект, тип, статус и источник. Пустая выдача может быть корректным результатом пересечения условий.

| Фильтр | Что проверяется | Особенность |
|---|---|---|
| Критичность | Уровень находки | Можно выбрать несколько уровней |
| Статус | Текущее состояние находки | Можно выбрать несколько статусов |
| Проекты | Идентификатор проекта | В запрос передаётся только первый выбранный проект; форма не обеспечивает выборку по нескольким проектам одновременно |
| Источник | `source_type` | Значения берутся из фасетов |
| Только в KEV (CISA), В БДУ ФСТЭК | Совпадение CVE находки с локальными каталогами | Это не проверка наличия произвольной записи обогащения |
| Есть CVE | Наличие CVE | Отдельный переключатель |
| Есть фикс | Заполненность `fixed_version` | Переключатель в панели показан для SCA; это не статус «Устранена» |
| EPSS ≥ | Максимальное значение EPSS по CVE находки из локальной базы | Шкала 0–1; нулевое положение снимает порог |
| CVSS ≥ | Максимальный `cvss_v31_score` по CVE находки из локальной NVD | Не универсальный максимум всех версий CVSS и не произвольный балл сканера; нулевое положение снимает порог |
| Возраст | Время первого обнаружения `first_seen` | Периоды: 24 часа, 7, 30, 90 дней либо без ограничения; это не возраст публикации CVE |

В панели могут появляться «Экосистема», «Провайдер IaC» и «Тип секрета». Их значения записываются в URL как `ecosystems`, `iac_providers` и `secret_kinds`, но общий серверный обработчик фильтров их не переносит в запрос к хранилищу. Не используйте эти переключатели как подтверждение ограничения выборки, в том числе перед экспортом.

Числа в фасетах служат выбору фильтров, а не проверке количества выделенных строк. Применение [сохранённого представления](Пользователь-Сохранённые-представления) заменяет весь фильтр, включая проект.

## Сортировка и колонки

Роль: просмотр и выше.

1. В меню сортировки выберите «Обнаружено», «Последний раз», «Критичность» или «Приоритет». Повторный выбор того же поля меняет направление.
2. В меню колонок выберите предлагаемый набор либо «Настроить колонки...».
3. В окне настройки выберите колонки и примените изменения. Набор доступных колонок зависит от вкладки типа находок.

Проверка результата: порядок строк соответствует выбранному полю и стрелке направления; заголовки таблицы соответствуют выбранным колонкам. После перезагрузки настройки колонок восстанавливаются в том же браузере для соответствующей вкладки.

Колонки и набор отображения хранятся локально в браузере отдельно от серверных сохранённых представлений. Изменение колонок не меняет набор полей экспортируемого файла. По умолчанию список сортируется по первому обнаружению в порядке убывания.

Кнопка «Обновить» в панели инструментов повторно запрашивает фасеты. Для контрольной проверки самих записей после внешних изменений перезагрузите страницу, а не полагайтесь только на эту кнопку.

## Группировка

Роль: просмотр и выше.

1. Откройте меню «Группировка» и выберите компонент, CVE, CWE или правило.
2. Раскройте доступную для раскрытия группу и выберите находку внутри неё.
3. Для возврата к отдельным строкам выберите «Без группировки».

Проверка результата: таблица переключается между групповыми строками и отдельными находками; при открытии элемента группы показана карточка конкретной находки. Группировка не объединяет записи в базе и не выполняет дедупликацию заново.

Групповой режим текущей страницы не предоставляет меню массового закрытия или назначения группы. Для массовой смены статуса используйте отдельные строки без группировки. Наличие серверных групповых методов не означает наличие соответствующих кнопок на этой странице.

## Предпросмотр и полная карточка

Роль: просмотр и выше. Изменить статус из предпросмотра может триаж и выше.

1. Нажмите строку находки. Откроется панель предпросмотра.
2. Просмотрите сведения, характерные для типа находки, и метаданные. Для перехода между загруженными строками используйте стрелки панели либо `j`/`k` и стрелки вниз/вверх вне полей ввода.
3. Нажмите «Открыть детали». Полная карточка открывается в новой вкладке.

Проверка результата: название и UUID полной карточки относятся к выбранной находке. Доступны вкладки из таблицы ниже. Отсутствие поля или данных обогащения не означает отсутствие уязвимости: интерфейс показывает только имеющиеся данные.

| Вкладка | Данные |
|---|---|
| Обзор | Описание; сведения по типу находки; источник, количество и даты обнаружений |
| Идентификаторы | CVE, CWE со ссылками на внешние каталоги; CPE при наличии |
| Обогащение | NVD, EPSS, KEV, БДУ, OSV, CWE; блок «Где видели» со связанными сканами |
| Комментарии | Обсуждение находки и форма добавления комментария |
| История | События изменений находки |

Для SCA показаны компонент, версия и исправленная версия при наличии; для SAST — файл, правило и фрагмент кода; для DAST — URL, метод и параметр; для IaC — данные ресурса и расположения; для секретов — доступные метаданные секрета. Приоритет отображается, если получен балл или его расчёт.

Кнопка «Назначить» в предпросмотре отключена. Назначение себе и снятие назначения выполняются в полной карточке. Предпросмотр закрывается крестиком, нажатием вне панели либо `Escape`; в списке `Escape` также снимает выделение. В полной карточке `Escape` возвращает к списку находок.

## Повторное обогащение

Роль: триаж и выше.

1. Откройте вкладку «Обогащение» полной карточки.
2. Если для источника показано пустое состояние с кнопкой «Обогатить сейчас», нажмите её.
3. После обработки обновите карточку и повторно проверьте вкладки обогащения.

Проверка результата: запрос принят сервером, а после обработки появились или обновились доступные данные. Постановка в очередь не гарантирует совпадение с каталогом; если данных нет, передайте администратору UUID находки и сведения об источнике. Поведение контура обогащения описано в [Диагностике](Администратор-Диагностика).
