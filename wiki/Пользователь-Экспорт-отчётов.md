# Пользователь-Экспорт-отчётов

Экспорт выполняется из меню «Экспорт» страницы «Находки». Требуется роль «Просмотр» или выше в проектах выгрузки; глобальный администратор может выгружать общую выборку.

Выгружаются записи по текущим серверным фильтрам, а не только загруженная порция таблицы и не только выделенные флажками строки. Выбор колонок в браузере не меняет поля файла. Группировка на экране не превращает выгрузку в список групп: основой остаются отдельные находки.

## Выбор формата

| Формат меню | Содержимое | Когда использовать | Ограничения |
|---|---|---|---|
| CSV | Таблица с заголовком, UTF-8 с BOM; идентификаторы, проект, критичность, статус, расположение, версии, показатели и назначение | Для табличной обработки и обмена плоскими данными | До 100 000 находок; нет колонки полного описания, комментариев и истории |
| Excel (XLSX) | Листы `Summary`, `Findings`, `By CVE`, `By Component`, `About` | Для анализа со сводками по CVE, компонентам, критичности и статусам | До 100 000 находок; описание в строке обрезается до 500 байт, `extra_urls` заполняется пустым значением |
| JSON (NDJSON) | Первая строка — объект `_meta`; далее отдельный JSON-объект находки в каждой строке | Для программной построчной обработки данных | До 100 000 находок; файл имеет расширение `.json`, но не является одним JSON-массивом |
| HTML отчёт | Сводки, таблица находок, разделы по CVE и компонентам; подробные карточки для небольшой выборки | Для чтения в браузере и печати | До 5 000 находок; при выгрузке из меню подробности включаются автоматически только при количестве не более 500 |

Названия листов и полей приведены как в создаваемых файлах. Экспорт находок не является резервной копией проекта: он не включает полный набор таблиц, участников, токенов, обсуждений и истории событий. NDJSON из выгрузки также не следует считать готовым отчётом для обратной загрузки через страницу «Импорт».

HTML формируется с сортировкой по критичности по убыванию, а при равной критичности — по последнему обнаружению по убыванию. Поэтому его порядок может отличаться от таблицы. CSV, XLSX и NDJSON используют параметры сортировки списка.

## Подготовка и скачивание

Роль: просмотр и выше.

Файл содержит сведения об уязвимостях. До выгрузки проверьте проект и условия отбора; храните и передавайте результат согласно внутренним правилам обращения с такими данными.

1. Откройте «Находки», задайте проект и нужные фильтры. Для перехода из меню проекта выберите «Экспорт»: этот пункт только открывает список находок с проектным фильтром.
2. Проверьте контрольные строки. Не используйте как ограничение экспорта фильтры экосистемы, провайдера IaC и типа секрета: текущий серверный разбор их игнорирует. Подробнее — [Работа с находками](Пользователь-Работа-с-находками).
3. Нажмите «Экспорт» и выберите формат. При пустой выдаче или уже выполняющейся выгрузке кнопка недоступна.
4. Дождитесь скачивания и сообщения «Выгрузка готова» с количеством записей.

Проверка результата: файл появился в загрузках браузера и открывается соответствующим средством. Проверьте идентификаторы контрольных находок, проект, состав полей и фактическое число записей. Успешное скачивание и число из уведомления не заменяют проверку целостности файла, особенно после сетевого сбоя.

## Проверка содержимого

Роль: просмотр и выше для формирования проверяемой выгрузки. Чтение уже скачанного файла не обращается к ролевой модели платформы.

1. Откройте скачанный файл.
2. Выполните проверку для выбранного формата из таблицы.
3. Сопоставьте контрольные записи с текущей выборкой платформы. При параллельном импорте или триаже данные могли измениться между запросами; экспорт не следует считать неизменяемым снимком транзакции.

Проверка результата: файл читается без ошибки формата, содержит ожидаемые контрольные записи и не выходит за согласованную область выгрузки.

| Формат | Что проверить |
|---|---|
| CSV | Наличие заголовка, корректное разделение колонок и русских строк; считайте записи CSV, а не физические строки файла: поля могут содержать переносы |
| XLSX | Открытие без восстановления повреждённой книги; количество строк данных на `Findings` и сводку на `Summary` |
| NDJSON | Первая строка содержит `_meta` с датой, фильтрами, оценкой количества и версией; последующие строки разбираются независимо; служебную строку не считайте находкой |
| HTML | Наличие сводки и таблицы; для выборки свыше 500 находок отсутствие подробных карточек является штатным поведением меню экспорта |

### Печать HTML

Роль для получения исходного отчёта: просмотр и выше.

1. Откройте скачанный HTML-отчёт в браузере.
2. Вызовите печать средствами браузера.

Проверка результата: предварительный просмотр печати содержит нужные разделы и таблицу. Отдельного пункта выгрузки PDF в меню платформы нет.

## Ошибки и ограничения

| Ситуация | Поведение | Действие пользователя с ролью просмотра и выше |
|---|---|---|
| Выборка больше лимита | Сервер отклоняет экспорт с ошибкой проверки; интерфейс предлагает «Уточнить фильтры» | Сузьте выборку; для HTML при допустимом общем объёме можно выбрать XLSX |
| Слишком много запросов | При работающем Redis ограничитель допускает до трёх одновременных выгрузок и до десяти запросов в пятиминутном окне на пользователя | Дождитесь завершения текущих запросов и окончания окна ограничения, затем повторите |
| Нет доступа к данным или завершилась сессия | Выгрузка не предоставляет ожидаемые данные либо запрос отклонён | Проверьте вход и проектное назначение; не меняйте URL в попытке обойти ограничение |
| Файл неполный или не открывается | Передача или обработка могла прерваться | Не используйте результат как окончательный отчёт; повторите меньшую выборку и проверьте файл |

После исправления причины повторите процедуру скачивания. Проверка результата: новый файл успешно открывается и проходит проверки содержимого выше.
