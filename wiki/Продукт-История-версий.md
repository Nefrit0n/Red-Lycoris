## Как определяется версия

| Источник | Значение и назначение |
|---|---|
| `VERSION` | Версия исходной поставки, которую по умолчанию читает `scripts/build.sh` |
| Метаданные сервера | Версия, коммит и дата передаются при сборке через параметры компоновщика; значения без передачи метаданных — `dev`, `unknown`, `unknown` |
| CI | Формирует следующий числовой тег, увеличивая последнюю часть найденного тега вида `X.Y.Z`, и передаёт его в сборку независимо от файла `VERSION` |
| `info.version` в OpenAPI | В проверенной спецификации — `0.1.0b`; само по себе это не обещание совместимости всех сборок |
| `frontend/package.json` | Служебная версия пакета интерфейса — `0.0.0`, не версия выпуска платформы |

Поэтому тег контейнера, содержимое `VERSION` и версия установленного сервера могут различаться. Префикс API `/api/v1` также не является номером выпуска приложения.

## Проверка установленной версии

1. Откройте `/api/v1/version` относительно адреса вашего экземпляра. Для стандартного прямого подключения к локальному серверу выполните:

   ```sh
   curl --fail --silent --show-error http://localhost:8080/api/v1/version
   ```

2. Проверьте ответ: сервер должен вернуть HTTP 200 и JSON с полями `version`, `commit`, `build_date` и `go_version` на верхнем уровне. Аутентификация для этого запроса не требуется.
3. Сопоставьте `commit` и `version` с выбранной сборкой. Значения `dev` и `unknown` означают, что метаданные не были заданы; в этом случае ответ не позволяет однозначно определить выпуск. Проверка завершена, когда установленная сборка идентифицирована по ожидаемым метаданным.

Источник поведения: [https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/api/version.go](https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/api/version.go).

## Совместимость схемы БД

Сервер при старте открывает миграции из каталога `migrations` и вызывает применение всех ещё не выполненных прямых миграций через golang-migrate. Если применение завершилось ошибкой, сервер прекращает запуск; отсутствие новых миграций считается нормальным результатом. HTTP-сервис запускается после этого этапа.

Наличие файлов обратных миграций не означает безопасного отката выпуска. Например, обратная миграция настроек источников проекта удаляет соответствующие столбцы вместе с их значениями. Замена образа на старый не вызывает обратную миграцию автоматически и не восстанавливает удалённые данные.

## Совместимость API

Маршруты приложения используют `/api/v1`. Однако код не задаёт срок поддержки устаревших полей и маршрутов или правило, запрещающее несовместимые изменения внутри этого префикса. Автоматическое увеличение последней части тега в CI не подтверждает отсутствие изменений контракта.

Спецификация OpenAPI описывает не все зарегистрированные маршруты текущей реализации. При проверке интеграции сопоставляйте спецификацию с обработчиками выбранного коммита, а не только с номером `v1`. Формат ответа также зависит от обработчика: например, сведения о версии возвращаются без обёртки `data`.
