# Администратор-Требования-к-рабочему-месту

Рабочее место обращается к веб-интерфейсу. Установка Go, Node.js или Docker на компьютер пользователя для работы с интерфейсом не требуется: клиентская сборка выполняется в образе frontend.

## Браузеры

В `frontend/vite.config.ts` не переопределён `build.target`, отдельная конфигурация Browserslist не задана. Зафиксированная в `package-lock.json` версия Vite — `8.0.9`; её стандартная цель сборки соответствует следующему набору:

| Браузер | Нижняя граница цели JavaScript-сборки Vite |
| --- | --- |
| Chrome | 111 |
| Edge | 111 |
| Firefox | 114 |
| Safari | 16.4 |
| Safari на iOS | 16.4 |

Это цель преобразования JavaScript, а не матрица испытаний Red Lycoris. Значения сверены с [константами Vite 8.0.9](https://github.com/vitejs/vite/blob/v8.0.9/packages/vite/src/node/constants.ts).

Интерфейс также использует Tailwind CSS 4. Для него разработчик компонента указывает Chrome 111, Safari 16.4 и Firefox 128. Поэтому Firefox 114 нельзя объявлять достаточным для всего интерфейса только по цели Vite. См. [совместимость Tailwind CSS](https://tailwindcss.com/docs/compatibility).

## Экран и возможности браузера

<!-- TODO: уточнить --> Минимальное разрешение экрана и допустимый масштаб интерфейса не определены. Ограничение ширины основного содержимого в Layout не является минимальным разрешением рабочего места.

Клиент использует JavaScript, cookie сессии `rl_session` и веб-хранилище для состояния интерфейса. Форма создания пользователя обращается к `crypto.subtle` для проверки пароля и к `navigator.clipboard` для копирования. Проверяйте доступность этих возможностей на фактическом адресе установки, а не только на `localhost`.

## Проверка рабочего места

1. Откройте адрес frontend, заданный администратором. Для локальной установки с портами по умолчанию это `http://localhost:3000`.
2. В инструментах разработчика браузера выполните только читающий запрос:

   ```javascript
   await fetch('/api/v1/version').then(async response => ({
     status: response.status,
     body: await response.json()
   }))
   ```

3. Войдите в свою учётную запись и проверьте наличие браузерных возможностей:

   ```javascript
   ({
     width: window.innerWidth,
     height: window.innerHeight,
     secureContext: window.isSecureContext,
     clipboard: Boolean(navigator.clipboard),
     cryptoSubtle: Boolean(globalThis.crypto?.subtle)
   })
   ```

4. Откройте список проектов и таблицу находок. Проверьте прокрутку, фильтры, доступность кнопок и закрытие диалоговых окон при используемом разрешении и масштабе. Если у вас есть административные права, дополнительно проверьте форму создания пользователя без её отправки.

Проверка результата: запрос версии должен вернуть HTTP `200` и JSON с полем `version`, а не HTML. После входа интерфейс должен оставаться авторизованным при обновлении страницы. Основные элементы должны быть доступны без обрезания; для функций копирования и проверки пароля значения `clipboard` и `cryptoSubtle` должны быть `true`. Отсутствие ошибок на этой проверке не заменяет утверждение матрицы совместимости.
