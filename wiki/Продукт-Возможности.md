# Продукт-Возможности

Ниже описаны функции, доступные через зарегистрированные обработчики API и страницы интерфейса. Возможности, представленные только полями схемы или заглушками, вынесены в [границы применимости](Продукт-Границы-применимости).

## Приём результатов

Через страницу импорта можно выбрать проект, загрузить отчёты и получить число добавленных и повторно встреченных находок, а также ошибки обработки. Отдельный путь приёма отчётов из CI использует проектный API токен и сохраняет сведения о коммите, ветке и сканере вместе со связями между сканом и находками. Это разные сценарии: ручной импорт не следует считать записью в истории сканов CI.

В серверном детекторе зарегистрированы следующие форматы. Совместимость конкретного отчёта определяется структурой, которую распознаёт парсер, а не только расширением файла.

| Источник отчёта | Поддерживаемое представление |
|---|---|
| AppScreener | JSON |
| SARIF | JSON SARIF |
| Trivy, Grype | JSON |
| Semgrep, gosec | JSON |
| TruffleHog | JSON-массив или NDJSON |
| Gitleaks | JSON |
| Checkov | JSON |
| OWASP ZAP | JSON |
| Универсальный формат Red Lycoris | JSON |

Источники: [https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/parser/detect.go](https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/parser/detect.go), [https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/api/import.go](https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/api/import.go), [https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/api/scans.go](https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/api/scans.go).

## Проекты и находки

| Блок | Реализованные функции |
|---|---|
| Проекты | Создание и редактирование, описание и теги, владелец и команда, параметры источника, сроки SLA, закрепление проекта, сводка и тренд |
| Доступ к проекту | Добавление и удаление участников, изменение проектной роли |
| Список находок | Поиск, фильтры, фасеты, сортировка, выбор столбцов и предварительный просмотр |
| Группировка | Группы по CVE, компоненту, правилу, секрету или CWE |
| Сохранённые представления | Сохранение, изменение и удаление наборов фильтров |
| Карточка находки | Контекст файла и строк, компонента, HTTP-запроса или ресурса IaC при наличии этих данных; сведения об обогащении, комментарии и история |
| Сканы проекта | Просмотр поступивших отчётов CI, метаданных и результатов импорта |

Настройки источника описывают проект, но не подключают автоматически Git-провайдер и не запускают проверку. Настройка сроков SLA сама по себе не подтверждает отправку уведомлений о нарушениях.

Повторное поступление определяется по SHA-256-отпечатку. При совпадении обновляются время последнего обнаружения и счётчик встреч; новая находка не создаётся. В текущей реализации отпечаток общий для БД, а не для отдельного проекта. Детали и последствия этого ограничения описаны в [границах применимости](Продукт-Границы-применимости).

## Триаж

Доступны подтверждение находки, изменение статуса, закрытие с причиной, повторное открытие, назначение и снятие ответственного. Комментарии можно добавлять, редактировать и удалять с проверкой прав. Для выбранных находок реализованы массовые операции со статусом, закрытием и назначением; отдельные обработчики выполняют операции над группами.

Интерфейс различает открытую и подтверждённую находку, ложное срабатывание, устранённую находку и принятый риск. Решение фиксирует пользователь: смена статуса не запускает исправление кода или повторную проверку сканером.

Источники: [https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/api/triage.go](https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/api/triage.go), [https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/api/comments.go](https://github.com/Nefrit0n/Red-Lycoris/blob/main/backend/internal/api/comments.go).

## Обогащение и приоритизация

Синхронизаторы загружают NVD, EPSS, CISA KEV, БДУ ФСТЭК, OSV, CWE и CPE в локальное хранилище. Обогащение находки использует локальные справочные таблицы; очередь фоновой обработки работает через Redis Streams. Синхронизация справочников и применение данных к находкам — отдельные операции.

| Функция | Результат |
|---|---|
| Обогащение | Дополнительные сведения из источников, для которых найдено соответствие |
| EPSS | Оценка, процентиль и история; использование изменения оценки при приоритизации |
| KEV | Признак включения в каталог, сроки и дополнительные признаки, учитываемые при приоритизации |
| OSV | Сведения о затронутых компонентах и исправлениях при наличии соответствия |
| Приоритет | Расчёт оценки от 0 до 10 с учётом исходной оценки, EPSS, KEV, БДУ, давности и наличия исправления OSV |
| Управление | Просмотр состояния синхронизаций; ручная синхронизация администраторами; полная синхронизация NVD и CPE; повторное обогащение |

В формуле также присутствует фиксированное значение `exposure = 5`; настройки этого коэффициента в функции расчёта нет. Полная формула относится к [описанию приоритизации](Система-Приоритизация).

## Отчётность и эксплуатация

| Блок | Реализованные функции |
|---|---|
| Дашборд | Сводные показатели, распределения по критичности и статусу, приоритетные находки и покрытие обогащением |
| Экспорт находок | CSV, NDJSON, XLSX и HTML с учётом фильтров и прав доступа |
| Учётные записи | Локальный вход, выход, смена пароля, обязательная смена пароля; хеширование паролей Argon2id |
| Администрирование пользователей | Создание и изменение, глобальная роль, активация и деактивация, удаление, сброс пароля, массовые действия и экспорт CSV |
| API токены | Создание проектных токенов с областями доступа и сроком действия, просмотр списка и отзыв |
| Аудит | Фильтрация журнала, карточка события, изменения и связанные события, статистика, поток новых событий, экспорт CSV и NDJSON |
| Диагностика сервиса | Проверки работоспособности и готовности, метрики и сведения о сборке |

Экспорт с суффиксом `export.json` реализован как NDJSON, а не единый JSON-массив. Экспорт HTML не является серверным формированием PDF.
