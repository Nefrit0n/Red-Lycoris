# Документация Red Lycoris

Актуальная документация поддерживается в [GitHub Wiki Red Lycoris](https://github.com/Nefrit0n/Red-Lycoris/wiki). Исходные Markdown-страницы находятся в [`wiki/`](../wiki/README.md) основного репозитория и публикуются workflow.

Старые файлы этого каталога временно сохранены только как переходные ссылки: их технические утверждения не являются источником истины. Они не удалены, потому что часть материала ещё не перенесена в Wiki без потери содержания.
